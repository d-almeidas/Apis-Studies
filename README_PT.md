## Roteiro

- **Requests**
  - Instalação e introdução a REST APIs
  - Métodos HTTP: GET, POST, PUT e DELETE
  - Query params, headers e cookies
  - Timeout, retry e boas práticas
  - Mini projeto: app de clima
  - Autenticação (basic e digest)

---

- **FastAPI**
  - Rotas e CRUD
  - Integração com banco de dados
  - Autenticação e testes
  - Docker e deploy
