  - Timeout, retry, and best practices
  -  Mini project: weather app
  -  Authentication (basic and digest)
  -------------------------------------
-  **FastAPI** 
  -  Routes and CRUD
  - Database integration
  - Authentication and testing
  - Docker and deployment
